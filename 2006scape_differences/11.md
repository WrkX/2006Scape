# 11. Treasure Trails sind unvollständig

GitHub Issue #250 beschreibt, dass Clue Scrolls und Rewards bereits vorhanden sind, die eigentlichen Clue-Schritte aber noch fehlen. Das System ist damit nicht vollständig spielbar.

OSRS besitzt dagegen ein sehr umfangreiches Treasure-Trails-System mit mehreren Schwierigkeitsstufen, STASH Units, Mimic und hunderten möglichen Schritten.
