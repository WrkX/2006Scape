# 22. Ground Items können aus Nachbarfeldern oder durch Hindernisse aufgenommen werden

Issue #581 beschreibt, dass Ground Items teilweise von angrenzenden Tiles aufgehoben werden können, ohne dass der Spieler direkt auf dem Gegenstand stehen muss. In Verbindung mit fehlenden Clipping Checks kann das sogar durch Zäune oder andere Hindernisse möglich sein.
