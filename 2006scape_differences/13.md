# 13. Farming ist kaputt bzw. unvollständig

GitHub Issue #576 bezeichnet Farming ausdrücklich als broken. Teile des Codes existieren, aber Events und Distance Checks müssen beziehungsweise mussten neu implementiert werden.

Im Repository existieren dennoch mehrere Farming-Komponenten, etwa für Flowers, Wood Trees, Fruit Trees und Farmers. Das Skill-System ist also nicht vollständig abwesend, sondern fragmentarisch beziehungsweise fehlerhaft.
