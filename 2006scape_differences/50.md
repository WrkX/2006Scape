# 50. 2006Scape besitzt eigene optionale Client-QoL-Modi

Über Argumente wie `-qol` beziehungsweise `-fixes` können zusätzliche Client-Fixes und Quality-of-Life-Funktionen aktiviert werden. PRs dokumentieren unter anderem Bilinear Minimap Filtering, einen Transparency-Fix und einen erweiterten Viewport.
