# 21. Melee-Clipping kann fehlen; Angriffe durch Wände sind möglich

Issue #593 dokumentiert fehlende Clipping Checks für Melee. Spieler können dadurch Gegner durch Wände oder andere Hindernisse angreifen.

Ein späteres Issue beschreibt konkret Kühe auf der anderen Seite eines Zauns, die vom Spieler angegriffen werden können, ohne korrekt zurückschlagen zu können.
