# Content Direction

## Do not clone modern OSRS wholesale

Current OSRS has diverged enormously from 2006 RuneScape.

Trying to reproduce everything would turn the project into a massive compatibility exercise.

Instead, selectively adopt ideas.

## Phase-one identity

Start with a mostly authentic late-2006 world:

- classic combat
- classic Wilderness
- no Summoning
- no Evolution of Combat
- old-school graphics
- old interfaces
- classic item progression
- traditional player trading

## OSRS-inspired additions worth considering

Quality of life:

- better bank controls
- XP drops
- shift-drop
- improved run toggle
- collection log
- useful interface improvements

Activities:

- rooftop-style Agility
- Motherlode-style Mining
- Wintertodt-like skilling bosses
- Slayer bosses
- solo-friendly PvM encounters

Systems:

- achievement tracking
- combat challenges
- account progression milestones
- optional Ironman-style tracking

## Original content

The strongest identity may be:

> “An alternate timeline where RuneScape continued from 2006 without Summoning, EoC, or the modern MMO direction.”

Possible additions:

- new islands
- lost kingdoms
- new quest lines
- old-school raids
- new dungeons
- new bosses
- niche equipment
- new minigames
- possibly an original skill later

Everything should visually and mechanically feel like it plausibly belonged in RuneScape 2.
